# XI-5 • SMAN 24 Jakarta

Website kelas XI-5, siap dipasang ke GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `assets/logo-xi5.png` — logo transparan XI-5
- `assets/gallery-01.webp` sampai `gallery-05.webp` — galeri kelas

## Cara pasang ke GitHub
1. Buat repository baru.
2. Upload `index.html` dan folder `assets`.
3. Di GitHub buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Simpan dan tunggu GitHub Pages selesai deploy.

Semua gambar memakai path relatif `assets/...`, jadi tidak bergantung pada file lokal komputer.
